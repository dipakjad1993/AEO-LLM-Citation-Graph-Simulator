# Screenshots

Add your screenshots here:

- `landing-hero.png` - Landing page hero section and info cards
- `dashboard-overview.png` - Full dashboard with results loaded
- `pipeline-stages.png` - Analysis pipeline progress view
- `report-sections.png` - Individual report section (e.g., SoMV)
- `usage-flow.png` - Upload and analysis workflow
- `pdf-export.png` - Generated PDF report sample

To capture screenshots:
1. Start the server (`npm start`)
2. Generate sample data or run analysis
3. Take screenshots of each section
4. Save them in this directory
5. The README will reference them automatically
